# SARA Real Estate Agent

Live app: https://ahmed-sleem.github.io/ai-sales-agent/

## Try the integrated demo

- The chat opens with **Demo mode: ON**. Use the existing chat composer or the suggested quick replies; the greeting, your messages, replies, and synthetic property photos all appear in the normal chat transcript.
- Demo mode runs locally from deterministic sample data and does not need an API key or call an AI provider.
- Switch **Demo mode** off to return to the existing live-agent send path. Switching modes does not clear the transcript.
- **Play demo conversation** runs the scripted city walkthrough in that same transcript. **Reset 3D city** only resets the visualization.

## Verification

Run `npm run verify` for typecheck, lint, unit tests, secret scan, dependency audit, production build, and Playwright smoke tests.
